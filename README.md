# TypingRaceSimulator

Object Oriented Programming Project — ECS414U

## Project Structure

```
TypingRaceSimulator/
├── Part1/    # Textual simulation 
└── Part2/    # GUI simulation 
```

## Part 1 — Textual Simulation

### How to compile

```bash
cd TypingRaceSimulator
javac Part1/*.java
```

### How to run

A main method has been added already in the class.

Then run:

```bash
java Part1.TypingRace
```
